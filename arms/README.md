# 腕の条件（T003）

| 腕 | 道具 | 禁止 |
|---|---|---|
| armB | 知識のみ。**Read だけ**（この環境に Grep / Glob は無い。実測済み） | シェル・コード実行。下請けは可 |
| armC | 知識＋コード実行。自分でパーサを書く | STEP / AP242 専用ライブラリ |

**腕に渡した文面は、このディレクトリの完成形がそのままである。**
差し込むのは走行番号だけ（`{RUN}` を `r1`/`r2`/`r3` に置き換える）。
3ファイルとも `bench/freeze.py` の硬の層に入れてあり、答案が書かれたあとに動いたら落ちる。

**なぜここまで書くか。**シリーズの別のベンチ（bim-bench）で、腕に渡すプロンプトを
差し込み式で持っていて**差し込んだ文がリポジトリのどこにも残っていなかった。**
しかもその文には「存在しないツールが使える」という誤りが入っていた。
本ベンチも v1.1.0 の時点では arms/ を持っていなかった。ここから残す。
